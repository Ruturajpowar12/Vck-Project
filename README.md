# Vck-Project

**Vck-Project** is a frontend web application developed during an OJT programme at **CodeWonders Tech LLP, Kolhapur**.
This project demonstrates modern React development with Vite, ESLint, and a polished component structure.

## 🚀 Live Preview
👉 https://vck-project-five.vercel.app

---

## 🧐 About

This repository contains a responsive React application built with **Vite**.
It was completed as part of an on-the-job training (OJT) assignment at **CodeWonders Tech LLP, Kolhapur**.
The app focuses on clean UI layout, modular component design, and maintainable frontend architecture.

## 🛠️ Installation

1. Clone the repository
```bash
git clone https://github.com/Ruturajpowar12/Vck-Project.git
```
2. Change into the project directory
```bash
cd Vck-Project
```
3. Install dependencies
```bash
npm install
```

---

## ▶️ Usage

Start the development server:
```bash
npm run dev
```

Open the URL shown in the terminal to view the application in your browser.
