## 🧐 About

This repository contains a responsive React application built with **Vite**.
It was completed as part of an on-the-job training (OJT) assignment at **CodeWonders Tech LLP, Kolhapur**.
The app focuses on clean UI layout, modular component design, and maintainable frontend architecture.

---

## 🧑‍💻 OJT Summary

- Organization: **CodeWonders Tech LLP**
- Location: **Kolhapur, Maharashtra**
- Training focus: **Frontend development with React and Vite**
- Skills demonstrated: React components, state management, routing, CSS styling, asset handling, and ESLint-based code quality
- Goal: Build a functional and professional web interface suitable for a modern business website

## 🛠️ Installation

1. Clone the repository
```bash
git clone https://github.com/Ruturajpowar12/Vck-Project.git
```
2. Change into the project directory
```bash
cd Vck-Project
```
3. Install dependencies
```bash
npm install
```

---

## ▶️ Usage

Start the development server:
```bash
npm run dev
```

Open the URL shown in the terminal to view the application in your browser.
